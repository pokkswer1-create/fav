# 구글 시트 출석체크 (이름 확대 시 사라짐 수정)

확대/축소 시 **이름이 가로로 잘리거나 사라지던 문제**를 막기 위해, 이름과 출석 선택을 **세로 카드**로 배치했습니다.

## 시트 준비

1. 구글 시트에 **`학생명단`** 탭을 만듭니다.
   - A1: `이름`
   - B1: `반` (선택)
   - A2부터 학생 이름 입력
2. **`출석기록`** 탭은 첫 저장 시 자동 생성됩니다.

## 코드 붙여넣기

1. 구글 시트 → **확장 프로그램** → **Apps Script**
2. 기존 `Code.gs` 내용을 이 폴더의 `Code.gs`로 **교체**
3. **+** → **HTML** → 파일 이름 `AttendanceCheck` → `AttendanceCheck.html` 내용 **붙여넣기**
4. 저장 후 시트로 돌아가 **새로고침**
5. 메뉴 **출석체크 → 출석체크 열기**

## 확대 화면 (태블릿/폰)

1. Apps Script → **배포** → **새 배포** → 유형 **웹 앱**
2. 실행 계정: 나, 액세스: 링크가 있는 사용자(또는 조직 정책에 맞게)
3. 배포 URL을 태블릿에서 열고, 화면 안 **확대** 버튼 사용

## 수정 요약

| 이전(문제) | 이후(수정) |
|-----------|-----------|
| 이름·선택박스 가로 배치 | 이름 위, 선택 아래 세로 카드 |
| `overflow`/`truncate`로 이름 잘림 | `word-break`, `overflow-wrap`으로 줄바꿈 |
| 확대 시 선택박스가 이름 가림 | 카드 전체 너비 사용, 확대 모드에서 글자 크기 증가 |

## 기존 출석체크가 이미 있는 경우

기존 `Index.html` 등에 비슷한 화면이 있다면, **이름이 들어 있는 요소**의 CSS에서 아래를 확인하세요.

- `overflow: hidden` 제거
- `text-overflow: ellipsis` 제거
- `display: flex` 가로 + `justify-content: space-between` 대신 **세로 배치** 사용
