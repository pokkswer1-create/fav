# 테마 수급 종목 분석기

기획서(`docs/종목분석기-기획서.md`)의 Phase 1 MVP 구현입니다.

## 기능
- 테마별 외인/기관/개인 수급 스캔
- **수급 유입 + 가격 정체** 후보 탐지
- 테마 대장 필터, 연속 수급, 유동성 필터
- 종목 3개월/6개월 가격·누적수급 차트
- 유사 구간 기반 +5% 도달 확률(참고용)
- 손절/익절/시간손절·비중 가이드
- 매수관심/관망/회피 코멘트

## 실행

```bash
pip install -r requirements.txt
PYTHONPATH=. streamlit run app.py
```

사이드바에서 **데모 모드**를 켜면 샘플 데이터로 바로 확인할 수 있습니다.  
끄면 `pykrx`로 실제 KRX 데이터를 조회합니다.

## 테스트

```bash
PYTHONPATH=. pytest -q
```

## 주의
교육·참고용 스크리너입니다. 투자 권유/수익 보장이 아닙니다.
