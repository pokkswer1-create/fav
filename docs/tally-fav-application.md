# Tally FAV 수업 신청서 — 설정 가이드

구글 폼 **「26년 FAV 수업 신청서」**를 Tally로 옮기고, 접수 데이터를 관리자 화면(`/admin/applications`)에 자동 저장하는 방법입니다.

---

## 진행 순서 (이 순서대로 하세요)

### 방법 A — API로 자동 생성 (권장)

```bash
TALLY_API_KEY=tly-xxx python3 scripts/create_tally_fav_form.py
```

Webhook까지 한 번에 연결:

```bash
TALLY_API_KEY=tly-xxx \
TALLY_FORM_ID=QKyeYX \
TALLY_WEBHOOK_URL=https://fav.vercel.app/api/webhooks/tally-application \
TALLY_WEBHOOK_SECRET=fav-tally-wh-7Kp2mN9xQ4vR8sT6wJ3hL5n \
python3 scripts/create_tally_fav_form.py
```

> `TALLY_WEBHOOK_SECRET`은 Vercel 환경변수에도 **동일하게** 등록해야 합니다.

### 방법 B — Tally UI에서 수동 생성

1. **Tally에서 폼 만들기** (아래 페이지별 블록 목록)
2. **Publish** 후 공개 URL 확인
3. **Webhook 연결** (Vercel 배포 URL + `/api/webhooks/tally-application`)
4. **테스트 제출** → 관리자 **수업 신청** 목록 확인
5. (선택) 공지/안내 **외부 신청 폼 URL**에 Tally 링크 등록

> 필드 **라벨(질문 제목)** 은 아래와 동일하게 맞춰 주세요. 서버가 라벨 키워드로 값을 읽습니다.

## Webhook 연동 (우리 서버)

### 1) Vercel 환경변수

`.env.example` 참고:

```bash
TALLY_WEBHOOK_SECRET=임의의_긴_문자열
```

Tally Webhook 설정의 **Signing secret**과 동일하게 넣습니다.

### 2) Tally Webhook URL

배포 후:

```
https://<배포-도메인>/api/webhooks/tally-application
```

Tally: **Publish** → **Integrations** → **Webhooks** → URL 입력 → Connect

(선택) HTTP Header:

| Header | Value |
|--------|-------|
| `Authorization` | `Bearer <TALLY_WEBHOOK_SECRET>` — 현재 코드는 `Tally-Signature` 서명 검증 사용 |

### 3) 저장 위치

| 수업 형태 | DB 테이블 |
|-----------|-----------|
| 체험 | `trial_class_applications` |
| 정규 | `regular_class_applications` |

관리자: **수업 신청** (`/admin/applications`) — 출처 `tally`로 표시

### 4) 테스트

1. Tally에서 테스트 제출
2. Tally Webhooks **Events log**에 2XX 확인
3. `/admin/applications`에 새 행 확인
4. `notes`에 `[source] tally`, 선택 클래스, 결제방법 등 기록 확인

## 공지/안내에 Tally 링크 넣기

관리자 **공지·안내** → **외부 신청 폼 URL**에 Tally 공개 URL (`https://tally.so/r/xxxx`) 입력.

공개 안내 페이지 `/announcements/[token]`의 **신청서 작성하기** 버튼이 Tally로 연결됩니다.
