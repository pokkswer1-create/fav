# 테마 수급 종목 분석기 기획서

## 1. 한 줄 정의

시황·수급·차트·테마를 바탕으로 **돈이 몰리는 종목**을 찾고,  
특히 **수급은 들어왔는데 아직 안 오른 종목**을 골라  
3·6개월 분석과 상승 가능성(%)까지 보여주는 개인용 분석 도구.

> 투자 자문/리딩/수익 보장 서비스가 아님. 교육·참고용 스크리닝 도구.

---

## 2. 출처 요구사항 정리

### 2.1 영상에서 말한 것 (`주식 초보자가 종목 분석기로 급등주를 잡는 법`)

| # | 요구 | 설명 |
|---|---|---|
| V1 | 종목 분석기 | 시황·수급·차트 패턴을 상시 분석 |
| V2 | 테마 파악 | 돈이 몰리는 테마 식별 (예: HBM, 전공정) |
| V3 | 대장주 선점 | 이미 오른 종목 추격이 아니라 상승 전 단계 포착 |
| V4 | 객관적 기준 | 뇌동매매 줄이는 규칙 기반 판단 |
| V5 | 퀀트 스캔 | 전수/테마 단위 자동 스캔 후 후보 선별 |
| V6 | 심층 리포트 | 재무 · 공시/재료 · 테마 · 수급 흐름 |
| V7 | 실전 코멘트 | 매수 / 관망 / 회피 판단 가이드 (자동 규칙 기반) |

### 2.2 사용자가 추가로 말한 것

| # | 요구 | 설명 |
|---|---|---|
| U1 | 투자주체 수급 | 외국인 · 개인 · 기관(세부 가능) 순매수/순매도 |
| U2 | 돈 몰림 종목 | 스마트머니(외인+기관) 유입 종목 탐지 |
| U3 | 상승 가능성 % | 얼마 오를지 확정이 아니라 **확률·예상 구간** |
| U4 | 수급↑ 주가 정체 | 테마 안에서 돈은 들어왔는데 아직 안 오른 종목 |
| U5 | 3개월/6개월 분석 | 선택 종목의 중기 수급·가격 추이 확인 |

## 3. 제품 목표 / 비목표

### 목표
- 매일(또는 장 마감 후) 테마·수급·차트 조건으로 후보를 자동 추출
- “돈 유입 + 미반영(가격 정체)” 셋업을 우선 노출
- 종목별 3M/6M 분석과 과거 유사 셋업 기반 상승 확률 제공
- 초보자도 왜 뽑혔는지 이유를 이해할 수 있게 설명

### 비목표
- 수익률 보장, 자동매매 집행, 유료 리딩 채널 복제
- 영상 제작자 비공개 로직 완전 복제
- “내일 +12.4%” 같은 확정 가격 예측

## 4. 핵심 유저 플로우

```
1) 테마/시장 선택
   ↓
2) 자동 스캔 (시황 필터 → 수급 → 차트 → 테마 점수)
   ↓
3) 결과 리스트
   - 돈 몰림 종목
   - 수급↑인데 아직 안 오른 종목 (핵심)
   ↓
4) 종목 상세
   - 3개월 / 6개월 탭
   - 외인/기관/개인 누적 수급
   - 가격·거래대금·패턴
   - 재무/공시 요약
   - 상승 가능성 % / 예상 구간
   - 매수·관망·회피 가이드
```

## 5. 기능 명세

### 5.1 시황 모듈 (V1)
- 코스피/코스닥 지수 등락, 시장 전체 외인·기관 수급
- 위험 회피일(시장 급락, 외인 대량 순매도)에는 후보 점수 하향
- 출력: `시장상태 = 공격 / 중립 / 방어`

### 5.2 수급 모듈 (V1, U1, U2)
- 종목별 일별: 외국인, 기관합계, 개인
- 기관 세부(선택): 금융투자, 보험, 투신, 사모, 은행, 연기금 등
- 지표:
  - N일 누적 순매수 대금
  - 시가총액 대비 순매수 비율
  - 외인+기관(스마트머니) 순매수
  - 개인 반대 매매 여부(역발상 보조)

### 5.3 테마 모듈 (V2, U4)
- 테마 → 종목 맵 (초기: 시드 맵, 이후 테마 데이터 연동)
- 테마 점수:
  - 테마 내 스마트머니 순매수 합
  - 테마 내 거래대금 증가율
  - 테마 내 상승 종목 비율
- 출력: 오늘 돈이 몰리는 테마 TOP N

### 5.4 차트/패턴 모듈 (V1, V3)
- 기본: 종가, 거래량, 5/20/60일선, 신고가 근접, 거래대금 급증
- “상승 전 단계” 판정 예시:
  - 정배열 전환 직전/직후
  - 박스권 상단 근접 + 거래량 증가
  - 급등(+X% 이상) 이미 발생 시 **추격 페널티**

### 5.5 핵심 셋업: 수급 유입 + 주가 정체 (U4, V3)
조건 예시(초기값, 추후 튜닝):
- 최근 20거래일 스마트머니 누적 순매수 > 기준(예: 시총 대비 또는 절대금액)
- 같은 기간 주가 수익률 ≤ +8% (또는 ≤ 0%)
- 거래대금은 평균 대비 증가
- 테마 점수가 상위권

정렬: `정체수급점수 = f(스마트머니 강도, 가격 미반영도, 테마강도)`

### 5.6 3개월 / 6개월 분석 (U5)
종목 상세에서 기간 토글:
- 가격 추이, 고점/저점, 기간 수익률
- 외인/기관/개인 누적 수급 곡선
- 거래대금 추이
- 기간 내 공시·재료 타임라인(가능 시)
- “이 구간에서 수급과 주가의 괴리” 요약 문장

### 5.7 상승 가능성 % (U3)
확정 예측이 아니라 과거 유사 셋업 통계:
- 예: “유사 셋업 이후 5거래일 내 +5% 이상 확률 62%”
- 예상 구간: P25 / P50 / P75 (예: +2% / +6% / +11%)
- 필수 표시: 표본 수, 측정 기간, 한계 문구

### 5.8 심층 리포트 + 코멘트 (V6, V7)
리포트 섹션:
1. 수급 요약
2. 테마 위치
3. 차트 위치
4. 재무 요약(시총, PER/PBR 등 기본)
5. 최근 공시/재료
6. 규칙 기반 코멘트
   - 매수 관심: 수급↑ + 정체 + 시황 중립 이상 + 패턴 통과
   - 관망: 조건 일부만 충족 또는 이미 일부 상승
   - 회피: 시황 방어, 수급 이탈, 과열(급등 후), 악재 공시

## 6. 화면 구성

### A. 대시보드
- 오늘 시장상태
- 돈이 몰리는 테마 TOP
- 핵심 후보(수급↑·가격 정체) TOP

### B. 스캔 결과
- 필터: 테마, 기간(20일/3M 기준), 최소 수급, 최대 상승률
- 테이블: 종목, 테마, 외인, 기관, 개인, 기간수익률, 점수, 태그

### C. 종목 상세
- 탭: 3개월 | 6개월
- 차트 2단: 가격 / 누적 수급
- 확률 카드: 목표 달성 확률 + 예상 구간
- 리포트 + 매수/관망/회피

### D. 관심종목/알림 (2단계)
- 조건 충족 시 텔레그램/이메일 알림

## 7. 데이터 / 기술 구조

### 데이터 소스
| 데이터 | 1차(무료·빠른 검증) | 2차(고도화) |
|---|---|---|
| 일봉 OHLCV | pykrx / KRX | 증권사 OpenAPI |
| 외인·기관·개인 수급 | pykrx | 한투/키움 API |
| 테마 맵 | 수동 시드 + 주기 갱신 | 테마 API/크롤링 |
| 재무 | pykrx/공시 요약 | FnGuide 등 |
| 공시·재료 | DART OpenAPI | 뉴스 API |
| 장중 실시간 | (초기 제외) | 증권사 OpenAPI |

### 논리 아키텍처
```
수집기(Collector)
  → 저장소(DB: 일별 시세/수급/테마)
  → 스캐너(시황·수급·차트·테마 규칙)
  → 확률엔진(유사 셋업 통계)
  → API
  → 웹 UI / 알림
```

### 권장 스택 (구현 시)
- Backend: Python (FastAPI)
- Batch: 장마감 후 일일 잡
- DB: PostgreSQL 또는 SQLite(MVP)
- Frontend: 단순 웹 대시보드(Streamlit MVP → Next.js)
- 알림: Telegram Bot (2단계)

## 8. 점수/규칙 초안

### 종목 점수 (0~100)
- 스마트머니 강도 40%
- 가격 미반영(정체) 30%
- 테마 강도 15%
- 차트 패턴 10%
- 시황 보정 5%

### 제외 규칙
- 관리종목/환기/거래정지
- 초저유동성
- 당일 이미 과열 급등(추격 방지)
- 명확한 악재 공시 직후

## 9. 단계별 범위

### Phase 1 — MVP (핵심만)
- 테마 시드 맵
- 외인/기관/개인 수급
- 수급↑ + 주가 정체 스캔
- 종목 3M/6M 상세
- 기본 점수와 후보 리스트

### Phase 2
- 시황 모듈
- 공시(DART) 연동
- 상승 가능성 % (백테스트 기반)
- 매수/관망/회피 코멘트

### Phase 3
- 장중 근접 실시간
- 알림
- 테마 자동 갱신
- 사용자 조건 커스텀

## 10. 성공 지표
- 스캔 1회에 이해 가능한 후보 5~20개 산출
- “수급↑·미상승” 후보의 이후 수익률을 백테스트로 검증 가능
- 사용자가 3M/6M 화면에서 수급-가격 괴리를 즉시 확인

---

## 11. 리스크 / 법적 고지
- 과거 통계 ≠ 미래 수익
- 확률 %는 참고 지표이며 투자 권유가 아님
- 데이터 지연(일봉 기준) 존재
- 테마 분류 오류 가능
- 서비스화 시 투자자문업 이슈 검토 필요 → 개인 분석 도구로 한정 권장

---

## 12. 초기 수용 기준 (기획 완료 정의)
기획이 구현 가능한 수준으로 끝나려면 아래가 결정된 상태여야 함:

1. MVP에 넣을 기능 = Phase 1 확정
2. 핵심 셋업 정의 = 수급↑ + 가격 정체
3. 상세 분석 기간 = 3개월 / 6개월
4. 예측 표현 = 확률 % + 구간 (확정가 아님)
5. 비목표 = 리딩/수익보장/자동매매 제외

## 13. 총정리 (영상 + 사용자 요구 매핑)

| 원하는 것 | 기획 반영 |
|---|---|
| 시황·수급·차트 분석기 | 모듈 5.1~5.4 |
| 돈이 몰리는 테마 | 테마 모듈 5.3 |
| 급등 전 대장주 관점 | 정체수급 셋업 5.5 + 추격 페널티 |
| 외인/개인/기관 | 수급 모듈 5.2 |
| 상승 가능성 % | 확률엔진 5.7 |
| 돈 들어왔는데 안 오른 종목 | 핵심 셋업 5.5 |
| 3달/6달 확인 | 상세 분석 5.6 |
| 리포트·판단 코멘트 | 5.8 |

**결론:** 영상에서 말한 분석 흐름과 사용자가 추가한 수급·확률·정체·3/6개월 조회를 한 제품으로 설계 가능.  
구현 시 Phase 1부터 가면 된다.

## 14. 수익률 기대값을 높이기 위한 추가 기획

> 아래는 “무조건 수익”이 아니라, **승률·손익비·손실 제한**을 개선해 장기 기대값을 올리는 기능이다.

### 14.1 효과 큰 추가 기능 (우선)

| 우선 | 기능 | 왜 수익에 도움인가 |
|---|---|---|
| P0 | **손절/익절/시간손절 규칙** | 진입만 잘해도 청산이 나쁘면 수익이 깎임. -5%~-8% 손절, +목표 분할익절, N일 무반응 시간손절 |
| P0 | **포지션 사이징** | 확신도·변동성 따라 1회 리스크 고정(예: 계좌 1%). 대박보다 파산 방지 |
| P0 | **시장 레짐 필터 강화** | 지수 급락·외인 대량 매도일엔 신규 진입 금지/비중 축소. 약세장 과매매 차단 |
| P0 | **백테스트 + 워크포워드** | 규칙이 과거에 먹혔는지 검증. 안 먹힌 조건은 제거 |
| P1 | **테마 내 대장주만** | 테마 상승률·거래대금 1~2등만. 잡주 추격 감소 |
| P1 | **상대강도(RS)** | 같은 테마/시장 대비 강한 종목 우선. 죽은 테마의 약한 종목 제외 |
| P1 | **연속 수급 필터** | 외인/기관 1회성이 아니라 2~5일 연속 순매수. 가짜 유입 걸러냄 |
| P1 | **유동성·스프레드 필터** | 체결 안 되는 저유동 종목 제외. 슬리피지 손실 감소 |
| P1 | **상관/중복 제한** | 같은 테마 5종목 몰빵 금지(최대 1~2개). 테마 붕괴 한 방에 계좌 방어 |

### 14.2 진입 품질을 올리는 추가 신호

| 기능 | 내용 |
|---|---|
| 거래대금 폭발 + 종가 상위권 마감 | 당일 매수세가 끝까지 버틴 종목 |
| 돌파 전 눌림(얕은 조정) | 급등 직후가 아니라, 수급 유지 + 짧은 조정 후 재개 |
| 공시/재료 캘린더 | 실적·계약·승인 일정 전후만 가중. 재료 없는 수급은 가중치↓ |
| 수급·가격 괴리 해소 시점 | “돈 들어왔는데 안 오름” 이후 **실제로 움직이기 시작**한 첫 돌파만 진입(선진입 대신 확인 진입 옵션) |
| 개인 홀로 매수 / 스마트머니 매도 | 역신호로 회피 점수 |

### 14.3 청산·리스크 (수익의 절반)

| 기능 | 규칙 예시 |
|---|---|
| 하드 손절 | 진입가 대비 -6% 또는 20일선 이탈 |
| 분할 익절 | +8% 절반 매도, 나머지 트레일링 |
| 시간 손절 | 10거래일 내 +3%도 못하면 퇴출 |
| 수급 이탈 청산 | 외인+기관 3일 연속 순매도면 종료 |
| 테마 붕괴 청산 | 테마 지수/평균이 고점 대비 -X%면 관련 포지션 일괄 축소 |

### 14.4 운영·검증 (가장 중요)

1. **셋업별 성적표**: 승률, 평균익, 평균손, 손익비, MDD, 표본수
2. **기간 분리 검증**: 2022 / 2023 / 2024… 구간별 성과 (한 해만 잘한 규칙 폐기)
3. **비용 반영**: 수수료·세금·슬리피지 넣어야 “진짜 수익” 보임
4. **과최적화 방지**: 조건 너무 많이 겹치면 미래엔 약해짐 → 핵심 5~8개만
5. **트레이드 저널**: 왜 샀는지/지켰는지 기록 → 감정적 개입 감소

### 14.5 넣지 않는 편이 나은 것
- 복잡한 AI “내일 종가 예측”
- 조건 20개 이상 과적합 스크리너
- 이미 +20~30% 급등한 종목 추격 알림
- 수익 보장형 자동매매 문구

### 14.6 권장 추가 로드맵

**Phase 1.5 (MVP 직후, 수익에 바로 영향)**
- 손절/익절/시간손절
- 1회 리스크 고정 사이징
- 대장주·유동성·연속수급 필터
- 간단 백테스트 성적표

**Phase 2.5**
- 상대강도, 재료 캘린더
- 돌파 확인 진입 모드
- 테마 붕괴/수급 이탈 자동 청산 알림

**Phase 3**
- 포트폴리오 상관 제한
- 워크포워드 자동 재검증
- 사용자별 규칙 성적 대시보드

### 14.7 한 줄 결론
수익을 올리는 추가는 **더 많은 종목 추천**이 아니라  
**① 가짜 신호 제거 ② 대장만 ③ 손절·사이징 ④ 백테스트로 규칙 검증** 이다.
